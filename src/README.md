# Source Code

Código fuente en Python para el proyecto.

Módulos:
- preprocessing.py - Funciones de limpieza y preparación de datos
- feature_engineering.py - Ingeniería de características
- models.py - Definición y entrenamiento de modelos
- evaluation.py - Métricas de evaluación y validación
- utils.py - Funciones utilitarias
- config.py - Configuraciones del proyecto

Todo el código está documentado y sigue buenas prácticas de programación.
