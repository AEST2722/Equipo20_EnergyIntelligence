# Notebooks

Jupyter notebooks utilizados para análisis, experimentación y desarrollo del proyecto.

Incluye:
- 01_eda.ipynb - Análisis exploratorio de datos
- 02_feature_engineering.ipynb - Ingeniería de características
- 03_baseline.ipynb - Modelos baseline
- 04_modelos_alternativos.ipynb - Experimentación con diferentes modelos
- 05_modelo_final.ipynb - Modelo final optimizado

Cada notebook contiene análisis, visualizaciones y explicaciones detalladas.
